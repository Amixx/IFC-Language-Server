# Schema Selection Samples

These minimal IFC STEP files are intended for manual testing of schema selection.

- Built-in schemas:
  - `minimal-ifc2x3.ifc`
  - `minimal-ifc4.ifc`
  - `minimal-ifc4x3-add2.ifc`
- Local custom schema names intended for additive/forced local EXPRESS testing:
  - `minimal-ifc4x1.ifc`
  - `minimal-ifc4x2.ifc`
- Unsupported schema behavior:
  - `minimal-ifc5.ifc`

The files are intentionally small and differ mainly in `FILE_SCHEMA(...)`.
